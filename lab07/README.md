# Лабораторная работа: Марковская модель погоды

![Скриншот приложения](demo.png)

В данной лабораторной работе реализовано имитационное моделирование смены погодных условий (Ясно, Облачно, Пасмурно) с использованием **цепей Маркова с непрерывным временем** (СМС).

---

### **1. Постановка задачи**
Целью работы является моделирование динамической системы «Погода» с тремя дискретными состояниями:
*   **1 — Ясно**
*   **2 — Облачно**
*   **3 — Пасмурно**

Единица времени — **1 день**. \
Переходы между состояниями происходят в случайные моменты времени согласно заданным интенсивностям.

---

### **2. Математическая модель**
В качестве основы модели используется **матрица интенсивностей $Q$**. \
Она описывает скорости переходов между состояниями. \
Сумма элементов каждой строки равна 0.

**Использованная в симуляции матрица $Q$:**

| | → Ясно | → Облачно | → Пасмурно |
| :--- | :---: | :---: | :---: |
| **Ясно →** | -0.40 | 0.30 | 0.10 |
| **Облачно →** | 0.40 | -0.80 | 0.40 |
| **Пасмурно →** | 0.10 | 0.40 | -0.50 |

---

### **3. Алгоритм моделирования**
1.  **Время в состоянии ($\tau$)**: Вычисляется по экспоненциальному закону $\tau = \frac{\ln(\alpha)}{q_{ii}}$, где $\alpha \in (0,1)$ — случайное число (Базовый Датчик).
2.  **Переход в новое состояние**: Выбирается как дискретная случайная величина с вероятностями $p_{ij} = -\frac{q_{ij}}{q_{ii}}$.
3.  **Теоретическое распределение ($\pi$)**: Находится из системы уравнений баланса $\pi Q = 0$ при условии $\sum \pi_i = 1$.
4.  **Статистическая обработка**: Накопление суммарного времени пребывания в каждом состоянии для получения эмпирических частот.

### **5. Анализ и выводы**
1.  **Сходимость**: Максимальное отклонение эмпирических данных от теоретических составило всего **~0.03** при времени симуляции 215 дней.
2.  **Адекватность**: Наибольшую долю времени система провела в состоянии «Ясно» (37.76%), что соответствует теоретическому прогнозу (38.10%) для данной матрицы интенсивностей.
3.  **Заключение**: Реализованная имитационная модель позволяет эффективно оценивать стационарные характеристики Марковских процессов. Визуализация в реальном времени подтвердила свойство «отсутствия памяти», характерное для экспоненциального распределения временных интервалов между переходами.
